Ce frontend provient directement du projet Next.js envoyé.

Les dossiers suivants ont été conservés :
- src/app
- src/components
- src/features
- src/lib
- public

La migration complète Next.js -> ReactJS nécessite :
- remplacement du App Router Next.js
- remplacement de next/link
- remplacement de next/navigation
- suppression des server actions
- migration vers react-router-dom
